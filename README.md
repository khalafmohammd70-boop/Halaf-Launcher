# HALAF TV Launcher — Home Dashboard

مشروع Android Studio بلغة Kotlin لواجهة شاشة رئيسية مخصصة لأجهزة Android TV / Android Box.

## الموجود في هذه النسخة
- واجهة أفقية بخلفية جبلية وبطاقات زجاجية بلون خمري.
- ساعة وتاريخ يتحدثان تلقائياً.
- بطاقتا الطقس ومواقيت الصلاة (قيم توضيحية حالياً).
- شريط نتائج مباريات بتصميم نموذجي (النتائج المعروضة تجريبية وليست بيانات مباشرة).
- شريط تطبيقات يكتشف التطبيقات المثبتة.
- الضغط على التطبيق يفتحه، والضغط المطوّل يزيله من الشاشة الرئيسية فقط.
- زر **تخصيص الشاشة** لإظهار/إخفاء الطقس ومواقيت الصلاة ونتائج المباريات.
- نافذة **إدارة التطبيقات** لإضافة التطبيقات وإزالتها.
- حفظ اختيارات المستخدم محلياً بعد إغلاق اللانشر وإعادة تشغيل الجهاز.
- دعم عناصر التركيز والتنقل الأساسية بواسطة ريموت التلفزيون (D-pad / OK).
- تعريف التطبيق كواجهة HOME وLeanback Launcher؛ يمكن اختياره كتطبيق الشاشة الرئيسية الافتراضي من إعدادات الجهاز.

## مهم قبل الاستخدام
بيانات الطقس والصلاة والنتائج الرياضية في هذه النسخة مجرد أمثلة تصميمية. لا يوجد اتصال بخدمة طقس أو مواقيت صلاة أو مزود نتائج رياضية حتى الآن. يلزم اختيار مزود بيانات وإضافة الربط قبل وصف النتائج بأنها مباشرة أو محدثة.

## البناء عبر GitHub Actions
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، وليس المجلد الخارجي نفسه.
3. افتح تبويب **Actions** وفعّل GitHub Actions إذا طُلب ذلك.
4. شغّل سير العمل **Build HALAF TV Launcher APK** أو ادفع commit إلى الفرع `main`.
5. بعد نجاح البناء افتح التشغيل ثم نزّل Artifact باسم `HALAF-TV-Launcher-debug`.

## إعدادات المشروع
- Package: `com.halaf.tvlauncher`
- Min SDK: 23 (Android 6.0)
- Target SDK: 28
- Compile SDK: 35
- Kotlin / Android Gradle Plugin: حسب ملفات Gradle المرفقة.

## ملاحظات التطوير
- هذه قاعدة مشروع مستقلة جديدة باسم HALAF TV Launcher، وليست تعديلاً مباشراً على كود RX Launcher الأصلي.
- لا تتضمن تطبيقات بث أو قوائم قنوات أو محتوى محمياً.
- لاختيارها كواجهة رئيسية: افتح إعدادات Android ثم التطبيقات الافتراضية / Home app واختر HALAF TV Launcher (تختلف التسمية حسب الجهاز).
